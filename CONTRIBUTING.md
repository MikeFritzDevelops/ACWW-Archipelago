# Contributing

Thanks for your interest in contributing to Animal Crossing: Wild World Archipelago!

## Reporting Bugs

Please use the GitHub Bug Report template whenever possible.

Include:
- Archipelago version
- BizHawk version
- ROM revision (and SHA-1 if known)
- Description of the issue
- Steps to reproduce
- Logs or screenshots if applicable

## Feature Requests

Please open an Issue describing your idea before starting work.

## Pull Requests

- Keep changes focused.
- Follow the existing code style.
- Test your changes before submitting.
- Explain what changed and why.
